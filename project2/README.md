# Commands Used
- `hostname` - to get the system's hostname
- `lsb_release -d` - to get the operating system details
- `uptime` - to check how long the system has been running
- `top -bn1 | grep "Cpu(s)"` - to get current CPU usage
- `free -h` - to check memory usage
- `df -h /` - to check disk space usage
- `hostname -I` - to get the IP address
- `who` - to list logged-in users

# Commands to Run the Script

chmod +x system_info.sh

Run the Script
./system_info.sh
